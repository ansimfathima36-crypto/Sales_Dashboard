# 📊 Flipkart Sales Dashboard – Excel

## 📌 Project Overview

This project is an interactive Sales Dashboard created using Microsoft Excel to analyze Flipkart-style e-commerce sales data and present important business insights through visualizations.

The dashboard helps understand sales and profit based on product category, customer city, and month.

## 🛠️ Tools & Skills Used

- Microsoft Excel
- Data Cleaning
- Pivot Tables
- Pivot Charts
- Slicers
- Data Analysis
- Data Visualization

## 📊 Dashboard Features

- Product Category-wise Total Sales
- City-wise Total Sales
- Month-wise Total Sales
- Product Category-wise Total Profit
- Interactive Product Category Slicer
- Interactive Customer City Slicer

## 📂 Dataset

The dataset contains 1,000 sales records with information such as:

- Order ID
- Order Date
- Product Category
- Product
- Brand
- Customer City
- Customer State
- Payment Mode
- Quantity
- Unit Price
- Discount Percentage
- Sales
- Cost
- Profit
- Order Status

## 🎯 Learning Outcome

Through this project, I practiced transforming raw sales data into an interactive Excel dashboard using Pivot Tables, Charts, and Slicers, while improving my data analysis and visualization skills.
